## 2. 五人样本与会话安排

目标样本（招募目标，不是已有结果）：2 位大学乒乓球运动员（A01、A02）、2 位普通球迷（F01、F02）、1 位教练或有教学经验的球友（C01）。五人是探索性小样本，不代表总体用户比例。

每场约 25 分钟：说明/同意 2 分钟；首次理解 2 分钟；路径 A 7 分钟；路径 B 8 分钟；访谈 6 分钟。时间不足时优先保留自主操作、事实记录和原话，不催促完成。

### 开场说明（照读）

> 谢谢你来试用。今天我们看产品是否清楚、有用，不是在考你。请按自己的理解操作，并说说你在找什么、预期会发生什么。遇到登录、付费、地区限制、验证码或打不开，我们就停在那一步，不绕过。官方页面打开不等于 PTTI 站内播放，也不保证你当前环境能看。收藏和笔记只用于本机试用；请不要输入真实隐私或导入个人备份。你可随时跳过或停止。我们只记录匿名编号、操作和你同意提供的反馈；默认不录音、不录像、不截屏。

只在参与者同意后开始。不要询问姓名、账号、密码、精确位置、联系方式或私人训练内容。默认用文字观察记录；录音、录屏、截图须另行征得明确同意。

## 3. 参与者任务卡

主持人一次只读当前任务，不指出按钮或示范操作。参与者求助时，先记下卡点和原话，再给最小帮助；完成状态记为“有帮助完成”，不算独立完成。

### A｜找比赛、判断来源、保存到个人空间

1. **首次理解**：“先看看这个产品。你觉得它能帮你做什么？你会从哪里开始？”观察前 30 秒，不解释用途。
2. **发现比赛**：“找一场你愿意看的比赛，并告诉我你为什么选它。”记录是否找到正确赛事、点击数（输入不计）、耗时、语言和求助。
3. **理解观看入口**：“你认为这个入口点下去会发生什么？你觉得 PTTI 已经确认视频能播放了吗？”先记录回答，再让参与者决定是否打开。
4. **打开来源（自愿）**：“如果你愿意，请前往来源页面，看看你能否观看，然后返回 PTTI。”分别记 PTTI 路由、外链/新标签打开、第三方页面加载、视频实际开始、完整观看；不要将前项当成后项。遇到登录、付费、地区门槛或 CAPTCHA 就停止，不提供账号或绕过。
5. **收藏**：“如果你想以后再找这场比赛，请按你认为合适的方式保存它。”不提示收藏按钮位置。
6. **找回与移除**：“去你的个人空间找回它。看完后，如果你不想保留，可以把它移除。”记录状态同步、反馈及误操作。使用本场测试数据，不碰参与者已有数据。

### B｜模拟战术选择并把想法带入 Journal

1. “试试这个情境，按你会做的方式处理这一分。请说说你在考虑什么。”不提示战术。
2. 选择后问：“这些解释对你有帮助吗？如果愿意，看看能不能把一个想法带到自己的训练记录里。”观察其是否理解没有绝对答案、条件会影响判断。
3. 若生成学习卡，问：“卡片里哪项对你最有用？你会怎么使用它？”观察是否理解这是模拟练习，不是实际比赛分析或 AI 录像诊断。
4. 观察其是否自行发现复制及手动回退。若复制失败，记录是否能理解备用文本。
5. 若参与者选择打开 Journal，让其自行新建一条**测试文字**、手动粘贴并决定是否保存。明确卡片不会自动保存；由参与者本人确认。不得覆盖或编辑其原笔记。
6. “你愿意在真实训练后再打开这条记录吗？如果愿意，会在什么时候用它？”记录具体理由，礼貌性肯定不等于回访意愿。

### C｜My Matches：用本人有权使用的视频记录一局（可选，仅适合运动员/教练）

只有参与者主动选择本人有权用于本机复盘的 MP4 时才做。不得要求展示视频内容、路径或真实文件名；不要把视频复制到研究记录。没有合适视频、文件选择器不可用或版本身份不明时，记录 `SKIPPED` / `BLOCKED`，不要换用模拟视频冒充真实媒体验收。

1. 让参与者在 My Matches 选择本机 MP4，观察画面是否真实载入，并尝试播放、暂停和 Seek。文件选择成功不等于已完成播放验收。
2. 让参与者明确选择首发球方，或保留 `UNKNOWN`；手动标记得分方及确能确认的发球方。观察比分规则、无效输入提示与撤销。不要替参与者判断来球或战术。
3. 查看洞察卡是否只汇报已标记分数、发球方覆盖及数据完整性；缺失数据应保持未知，不应出现未经支持的技战术结论。
4. 让参与者主动进入现有 Pro Lab。记录原手动证据身份、比分、逐分数及边界复核状态是否保留。Pro Lab 的导入草稿不等同正式训练复盘报告；同会话路径不应被描述成媒体独立核验。
5. 参与者主动导出 JSON 后，只在本机 QA 临时位置解析/核对结构。确认没有本机绝对路径、真实文件名或媒体字节；不得将文件交给研究者，除非参与者另行明确同意。
6. 若用导出的 JSON 再走导入流程，确认本机视频需在新会话重新选择，旧时间边界处于待重新确认状态；不把旧边界直接当作当前媒体资格。

此路径的数据边界预期：`LOCAL_SESSION_ONLY`、`USER_MANUAL`、`USER_RECORDED_NOT_INDEPENDENTLY_VERIFIED`；未关联的公开比赛/来源 ID 为空。若实际界面与预期不符，立即停止导出或后续导入，记录版本、步骤与脱敏状态，不保存私人媒体画面。

## 7. 事先约定的决策规则（门槛，不是测试结果）

- **立即停止：** 出现比赛/来源错配、收藏或 Journal 数据丢失、未确认即写入、隐私暴露、模拟内容被误认为真实比赛分析。记录事实，暂停该路径，修复或澄清后再继续。
- **找赛与信任：** 若至少 4/5 能独立找到目标比赛并完成收藏/找回，且至少 4/5 正确理解官方外链不代表 PTTI 已确认播放，可认为本轮方向性信号良好。外站播放另行统计，不是 PTTI 找赛成功的唯一标准。
- **学习桥梁：** 至少 3/5 主动生成卡片，且至少 3/5 能提出一个愿在真实训练中观察的问题，才继续投资当前学习桥梁；若觉得无用，先澄清使用场景，不扩建 Arena。
- **重复使用：** 少于 3/5 能给出具体再次使用理由时，不宣布价值成立；追问实际缺失内容。
- **共同障碍：** 两人或以上在同一步出现同类停顿、误解或求助，列为下一轮优先问题；严重误导即使只出现一次也优先处理。
- 这是小样本产品决策门槛，不是统计显著性结论，也不构成发布或媒体授权。

## 8. 三项最值得验证的假设

1. **找赛与观看信任：** 普通球迷能否快速找到感兴趣的比赛，并理解 PTTI 提供的是官方站外入口，而非承诺站内播放？
2. **收藏带来回访价值：** 用户是否会主动收藏、随后在个人空间找回，并认为值得回来使用？
3. **模拟学习卡能迁移到训练：** 运动员/教练是否认为多方案解释能帮助形成真实训练观察问题，并愿意亲手放进 Journal？

## 9. 反馈后如何选下一项开发

1. 先处理安全、数据、身份或媒体状态误导问题。
2. 按“失败/求助人数 + 影响 + 用户原话 + 可复现步骤”排序；共同障碍优先，严重误导无需等待第二例。
3. 找赛通过但学习卡价值弱：不扩 Arena，先调整学习卡表达或使用时机，再做窄测。
4. 用户能找比赛但不回访：改善收藏可发现性/回访路径，不先加社交或云同步。
5. 如果候选身份无法确认或产品打不开：先恢复可验证的测试入口；概念访谈不能代替产品使用性结论。
