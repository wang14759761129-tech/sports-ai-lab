# 给球迷的三分钟 PTTI Alpha 试用

你好，想请你试一下 PTTI：它帮你找乒乓球比赛，并分清应该去哪一个官方页面观看。请按自己的理解操作，观察者先不教学。只在能打开本机网站的设备上试用：http://127.0.0.1:4174/ 。外地设备打不开这个 localhost 链接。

## 三分钟操作卡

| 时间 | 你要做的事 |
| --- | --- |
| 0:00–0:45 | 在“看比赛”中搜索“樊振东”，找到他对林高远的比赛，打开详情。 |
| 0:45–1:30 | 看来源和验证状态，前往官方视频页尝试观看，再返回 PTTI。需要登录、地区不可用或验证时如实记录，不绕过。 |
| 1:30–2:00 | 复制比赛页面链接，粘贴到自己的笔记或书签。重新打开该链接，看看是否恢复同一场比赛。 |
| 2:00–3:00 | 打开“反馈建议”，填写实际体验，保存到本机，再导出 JSON。告诉观察者哪里最困惑。 |

三分钟结束即可停下。官方页面加载或播放受限时记录“受限 / 未完成”，不用为了完成测试等待或绕过限制。可以改用 English；无需填写姓名、手机号或任何账号信息。

“官方页面画面已核验”只表示先前指定浏览器中的连续画面证据，不保证你的设备、地区、声音或 PTTI 站内播放。赛事页和新闻报道不等于单场视频。保存链接不保存比赛视频。

## 反馈如何保存

表单只保存在当前浏览器的本机存储中；导出只生成 `ptti-web-feedback.json`，没有自动上传或线上收集。关闭隐私浏览窗口或清理存储可能使记录消失。试用者可以选择交付导出文件供人工查看；不愿交付也可以，只口头说明问题即可。未经主动交付，不收集文件。

追问最多三句：**哪一步最难？你如何理解观看状态？你会下次再用吗，为什么？**

只有观察到的行为和用户本人回答才填写。不要把页面打开当作播放成功，不要填写猜测的成功率。若观察者提供帮助，不能算“独立完成”。
