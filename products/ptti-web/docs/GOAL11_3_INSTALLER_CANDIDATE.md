# Windows installer candidate

This is an actual ZIP/script user-level installer, not a signed EXE/MSI. Extract the complete ZIP and run Install.cmd. It uses existing Windows PowerShell5.1; no elevation, registry, scheduled task, desktop replacement or auto-launch. A pre-existing installation or incomplete staging directory is refused rather than overwritten.

The package uses the exact RC1 San00933e351edc / Core304eb661 binaries and site bytes. It does not rebuild the application. An auditable installer-only overlay selects4177 and adds a per-process random named-pipe/token lifecycle controller; original HTTP server, original manifest, licenses, site, runtime and synthetic demo are retained. The derived manifest and package receipt hash every installed program file. SHA proves integrity, not publisher authenticity; this candidate is unsigned.

Build: `node scripts/build-installer-candidate.mjs`. Existing7-Zip creates a low-compression, single-thread ZIP; it is a build-only tool and is not redistributed (installed License.txt: LGPL, BSD and unRAR notices). Redistributed Node includes its complete MIT/third-party license; React, ReactDOM and Scheduler carry MIT notices. Windows components are not redistributed.

Output: `%USERPROFILE%\PTTI\Installer-Candidates\goal11-3-rc1\PTTI-Web-Pro-Installer-Candidate-rc1.zip`, adjacent SHA256 and build receipt. Install destination: `%LOCALAPPDATA%\PTTI-Web-Pro-Installer-Candidate\rc1`. Start-PTTI-RC.cmd opens the candidate; Stop-PTTI.cmd stops only its own token-authenticated process and releases HTTP connections; export unsaved work first. Uninstall.cmd validates program hashes, stops only that candidate, removes only matching program files, and preserves logs, unknown files and directories. A modified program file blocks uninstall for inspection. No recursive deletion of a user directory. Remaining logs may be inspected and manually archived before reinstallation; installation intentionally refuses existing directories.

No videos/reports are uploaded or persisted by default. Only loopback HTTP; original CSP, public0, SIMULATED_ONLY and LOCAL_SESSION_ONLY gates remain. No35-source internal index. Control tokens stay in local logs/control.json and are never web-served; logs contain no video paths/content. The application is not a persistent Windows service; launcher creates a detached process and reuses verified identity. No old processes are terminated.

Test: `node scripts/check-installer-candidate.mjs` on a machine without this candidate installed. It extracts the real archive, rejects altered payload, installs, refuses overwrite, cold-starts4177, reuses control identity, stops, uninstalls, preserves a test user file and verifies4174/4176/desktop unchanged. It deliberately leaves uninstall evidence. Actual outcomes are in `.alpha-qa/goal11-3/installation-report.json`; browser evidence is separate. RAM below2.5GiB blocks Chrome; no launch-by-human, real video, reboot/cross-machine, signing or installer GUI claims are implied.
