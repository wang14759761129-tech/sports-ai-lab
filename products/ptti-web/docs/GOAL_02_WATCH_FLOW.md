## 五分钟试用路径

1. 打开 http://127.0.0.1:4174/ 的“看比赛”。搜索“樊振东”或“Fan Zhendong”。
2. 选择男单和“已核验官方视频”，找到 Fan Zhendong vs Lin Gaoyuan。
3. 点击“查看比赛详情 / 保存入口”，辨别比赛双方、赛事、来源类型和核验状态。
4. 点击“前往官方视频页面”，在官方平台尝试观看；返回 PTTI。
5. 点击“复制比赛页面链接”，保存到自己的笔记，或收藏当前页面。刷新或重新打开保存的 URL，应恢复同一场比赛。
6. 返回比赛列表，比较 Fan Zhendong vs Wang Chuqin（赛事页面）与 Sun Yingsha vs Chen Xingtong（新闻报道）。它们不提供单场视频入口。

比赛定位示例：http://127.0.0.1:4174/?match=doha-2023-ms-sf-fan-lin

链接只包含公开比赛 ID；未知 ID 提供恢复列表入口。链接不会上传数据，也不能让外地设备访问 localhost。反馈仍仅保存在浏览器本机，须主动导出。

运行浏览器回归需要本机已安装 Chrome，以及可用的 Playwright 模块（本轮使用桌面应用自带运行时，无依赖安装）：

```powershell
$env:PTTI_PLAYWRIGHT_MODULE = '<已安装 Playwright 的 index.mjs 绝对路径>'

```

默认测试地址 4174，可通过 `PTTI_WEB_URL` 指向自己启动的本地服务。若标准模块解析能找到 Playwright，则无需指定模块路径。
