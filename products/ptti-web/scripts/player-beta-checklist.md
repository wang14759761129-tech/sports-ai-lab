未发布；不是 RELEASE-READY。仅源码、离线组件与构建验收通过。真人招募 0/5，测试 0/5。浏览器 GUI、真实 MP4 选片与播放、SVG 下载及外站视频均 NOT_TESTED。

## 启动与回滚

需要已安装 Node.js 20+。解压到新目录，双击 Start-Player-Beta.cmd；手动打开 http://127.0.0.1:4199/ 。不会自动打开浏览器。也可在包目录运行 `node server.mjs 4199`，端口占用会退出，绝不结束其他进程。只绑定本机，无上传接口。CSP 禁止嵌入外站视频；官方外链仍由浏览器单独打开，链接不代表播放授权。

首次试用应使用独立浏览器配置，避免与旧版本同源本地收藏/Journal 混用。本候选本身不迁移或清除数据。关闭终端或 Ctrl+C 即停止；回到旧版本原入口就是回滚，不替换 Desktop、Launcher、数据库或已有候选。移除本包不会清除浏览器已有数据。未提交比赛编辑只在当前页面内存中，切换工作区保留；刷新、关闭页面会丢失，先使用原有导出保存记录。

复现：在 SAN 原分支干净工作树、依赖及固定 Playback 源可用时运行 `npm run build:player-beta`。脚本执行 TS、全部生产构建门禁及47/48定向测试；目录按源码 SHA 唯一命名，已存在就停止，不覆盖。包 manifest 记录来源 SHA 与文件 SHA256。不代表 GUI 验收。

## 五人试用（由负责人另行招募，不自动联系任何人）

至少包含一位平时只看比分、不看回放的人。只用本人有权使用的本地素材；原话、观察行为、研究者推断分栏记录，不上传视频或私人文件名。

每位 P1 / P2 / P3 / P4 / P5 都检查以下相同流程，记录 PASS / FAIL / NOT_TESTED 与障碍：

1. Cinema 8/19/8、Highlights 官方外链、返回、Collector 收藏/取消及空状态；严格区分外链、可播放、已观看。
2. My Matches 选择授权 MP4，手工逐分到 7:7 / 9:9 / 10:10，检查领先、追平、反超、完成/未完成及未知发球信息；不把手工记录当独立核验。
3. 留一条未提交编辑，打开 Premiere，上一张/下一张、键盘 Tab/Enter/Space、窄屏与 reduced-motion，定位记录只移动焦点不 Seek；返回后编辑与同一播放器会话仍在。
4. 检查 SVG 字段预览后保存：仅比分、完成状态和固定声明，无姓名、路径、文件名、私人媒体。个人报告与 One Game 原始导出 Schema 不变。Pro Lab 往返不丢记录。
5. 选实际记录的9:9，确认用途再进 Arena；历史数据/假设选项明确分隔；非9:9与空记录不能启动。选择、重试、返回报告/Premiere后比赛、报告和Journal均无模拟写回。

不要求参与者复制私人数据到观察表；遇浏览器控制或媒体权限阻断记 BLOCKED，不绕过、不反复重试。五人体验只用于定性反馈，不作统计结论或发布许可。
