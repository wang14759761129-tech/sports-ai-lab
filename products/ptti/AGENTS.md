# PTTI desktop delivery

After an effective source change, preserve research boundaries and user data. Commit clean source after appropriate tests, then run `.venv\Scripts\python.exe scripts\dev_sync.py` from this project.

Never lower resource guards or terminate user programs. If resource or validation checks block deployment, report `DESKTOP_UPDATE_PENDING` and keep the active pointer unchanged.

Report these independently: CODE_COMMITTED, TESTS_PASSED (scope), WINDOWS_BUILD_VERIFIED, DESKTOP_UPDATED, NATIVE_GUI_VERIFIED. A commit or pointer simulation is not native GUI acceptance. Do not publish releases or change Stable unless separately authorized.

Preview deployment must preserve `%LOCALAPPDATA%/PTTI-Dev/VideoFirst-R4-Preview` data. Production DB, official TEST, GAME_5 and frozen algorithms are out of scope. Remote release discovery does not authorize download/install. Until an authenticated update signing policy and explicit Preview consent workflow exist, remote installation stays disabled.
