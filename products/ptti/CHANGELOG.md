# Changelog

## 0.1.1 — 2026-10-05

Research integration and release hardening. Non-squashed subtree preserves the original release history. Recovered Protocol v0.3 references and 21-field compatibility analysis; dedicated adapter with original values/provenance, pre/post score conversion and explicit subtype warnings; uncertainty-aware denominators/evidence gates; Chinese import and metric copy; refreshed Windows handoff. Research conclusions unchanged; Pilot 2 not started. Unknown core identity/scores reject; mapping/measurement limitations remain documented.


## 0.1.0 — 2026-10-05

First usable PTTI release.

- Point-by-point UTF-8 CSV ingestion and field/score/service validation, with separate errors and warnings.
- SQLite match persistence and a reopenable local match library.
- Match analytics, score charts, rally profile and momentum runs.
- Deterministic tactical evidence/insights with denominators and sample-size labels.
- Point explorer with search and server filtering.
- JSON and standalone HTML export; dashboard printing.
- Windows desktop directory packaging and Chinese Kaikai handoff archive.
- Explicitly labeled synthetic sample data.
- Automated coverage: 16 tests passing at freeze.

Known limitations: historical v0.3 sources absent; schema is 1.0.0-new and compatibility is unverified. English UI supports Chinese user names. No partial mid-game clips, doubles identity, cross-game starting-server checks, annotation consistency validation or match-format enforcement. Metric drilldown is broad, not exact. No JSON reimport, data editing, video or LLM. Deletion is API-only. WebView2 Runtime required; clean-machine/Kaikai testing is still pending. Printing and a user-selected export file save have not been fully tested. Large-match performance is unverified.
