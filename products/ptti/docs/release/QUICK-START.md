# PTTI 0.1.2 快速开始

完整解压 ZIP。推荐运行 INSTALL.cmd：复制程序到当前用户的应用目录，创建桌面与开始菜单快捷方式；无需管理员权限。也可直接打开 PTTI/PTTI.exe，保留旁边的 _internal。需要 Windows 10/11 x64 与 WebView2 Runtime。

1. 首次使用说明中点“加载示例”，了解分析页面。示例明确标为合成。
2. 首页点“导入一场比赛”。填写球员和比赛信息，下一步选择 UTF-8 CSV。
3. 自动检查只预览，不保存。错误必须修复；警告允许继续，但相关指标可能不可用。
4. 点“保存并进入比赛分析”。总览、发接发、第三板、回合、逐分、证据可以直接切换。
5. 逐分页可按局、发球方、得分方筛选，搜索备注或只看警告/不确定记录；原始研究字段按需展开。
6. 比赛库可搜索、按日期筛选、打开比赛。删除需再次确认，不可撤销。
7. 导出分析：保存 JSON 或 HTML。打印/PDF 为实验功能，针对当前分区；打印未作为交付承诺。
8. 退出重开，比赛和设置仍在。设置支持浅色、深色、跟随系统，以及打开最近保存的比赛。

数据位置：%LOCALAPPDATA%\PTTI\matches.db，正常卸载保留数据。安装目录：%LOCALAPPDATA%\Programs\PTTI\versions\0.1.2。开始菜单卸载入口只移除当前版本应用；请先关闭程序。

“未知”与“无法判断”不是零。不适用单独排除；有效战术样本不足时不显示猜测比例。数据充足只描述当前样本，不是科学结论。
