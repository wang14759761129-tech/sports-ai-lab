`media_sha256` is null and `media_sha256_status` is UNKNOWN for all public sources: a source URL or input JSON hash is not a video hash. `input_sha256` identifies the pinned source snapshots normalized to LF, not video bytes. The projection contains no media bytes, private file paths or internal review records. Identity VERIFIED applies only to the recorded source/publisher field; it does not mean currently accessible or played. UNVERIFIED means the relevant claim has not been verified. REFERENCE_ONLY means a recorded reference, not a grant. LICENSED requires a verifiable license for the precise subject, use, target and period; USER_OWNED is a user assertion with limited scope, not independently validated ownership. DEMO means synthetic and must not join to a real match without separate proof. None of these labels implies any other label or permission.

`external_navigation=ALLOWED_AS_RECORDED` is only the source package's scoped official-page-link disposition, not a current reachability or viewing claim. Page and actual playback are NOT_TESTED; current-session eligibility is NOT_EVALUATED_CURRENT_SESSION. Embedding is UNKNOWN; downloading and redistribution are NOT_GRANTED. The public adapter does not serve imagery, video, media caches, local file paths, or the internal GOAL19 observation addendum. Do not substitute this projection for the existing Review Targets/Evidence Pack contracts.
