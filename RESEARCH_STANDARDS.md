# Research Standards

**Status:** SYSTEM BUILT / PRACTICING

Every future project should make this chain visible:

1. **Question** — define one answerable question.
2. **Data** — record source, permissions, variables, and missingness.
3. **Method** — explain the calculation or procedure simply enough to repeat.
4. **Result** — report outputs without overstating them.
5. **Limitation** — state what the data and method cannot support.
6. **Reproducibility** — include files, instructions, and an environment assumption.
7. **Reflection** — record what changed in my understanding and the next question.

This is a working standard, not a claim that every skill is mastered.
