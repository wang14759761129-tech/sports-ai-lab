# Sports AI Lab

An undergraduate workspace for exploring table tennis data and human performance. The aim is to develop clear questions, simple baselines, and reproducible analysis before introducing complex models.

中文：以真实体育问题为起点，先定义指标和数据，再考虑 AI 方法。

**Status:** Planning stage. No dataset, trained model, validated finding, or completed experiment is included.

## First candidate question

Within one match, how does the observed proportion of points won on serve vary between the first and second half of each game?

This is a descriptive learning question, not a proposed causal claim about fatigue, tactics, or skill. Definitions and a data source must be settled before analysis. See [the project brief](projects/001-serve-description/README.md).

## Structure

- [projects/001-serve-description/](projects/001-serve-description/README.md): one candidate question and its decisions.
- [data/](data/README.md): data source and sharing requirements.
- [reports/](reports/README.md): future results with methods and limitations.

## Working sequence

Question → operational definitions → permitted data → checks → descriptive baseline → interpretation → limitations.

Keep this workspace in planning while learning the foundations in `learning-lab`. Add code and environment instructions only when an analysis is ready to implement. There is currently no software to run.
