# PTTI DEV HUB
Run Update-DevHub.ps1 to refresh status.json and the local HTML. Open-PTTI-DevHub.cmd refreshes and opens the HTML using Windows file associations. No server, push, merge or deployment is performed. Port checks are listener-only; process identity and GUI status are not inferred. The filename screen does not scan history or establish rights/secret safety. Before any push, verify repository privacy, review all newly reachable Git objects and attachments, run a professional secret scan, prepare exact refs and hashes, and obtain explicit authorization. Draft PR creation requires a pushed branch and separate authorized GitHub write.
