# Data dictionary

**Status:** PRACTICING — synthetic practice data

| Field | Meaning | Unit / rule |
|---|---|---|
| `match_id` | Identifier for the practice match | Text |
| `game_id` | Order of a game within the match | Integer, starting at 1 |
| `player_score` | Points scored by the player | Points |
| `opponent_score` | Points scored by the opponent | Points |

The CSV is synthetic and exists to make the first analysis reproducible. It does not represent a real athlete or competition. Any future real data must have permission and documented collection conditions.
