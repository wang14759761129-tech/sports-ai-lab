# PTTI Innovation Registry — open-ended candidates

No entry is a claim of patentability, uniqueness, ownership of athlete rights, or a shipped technical asset. Each is a testable product hypothesis. All comparisons below are intended differentiation, not completed market research.

| Candidate | Need / intended difference | Direct action / minimum prototype | Rights and data | Feasibility / accumulation |
|---|---|---|---|---|
| Moment Cards → Moment Passport | Keep an observation connected to its evidence, unlike a loose bookmark | Save time + note; later reopen exact verified source | Media identity, time base, source link; no copied clip by default | Bookmark PROTOTYPE; source-safe Passport PROPOSED; annotations accumulate |
| Match Intelligence | Explain a match without leaving it | Open sourced match desk | Match/source IDs, versioned statistics, permissions | Main dependency; persistent evidence graph |
| Fan Arena | Make watching participatory | Choose → settle → review | Demo or verified result; community consent/moderation | Demo PROTOTYPE; real events PENDING; judgment history |
| Rally DNA | Describe repeatable tactical patterns | View one annotated rally fingerprint | Owned/authorized media, human labels, validation | Research PENDING; annotation ontology and dataset |
| Prediction Engine | Compare personal intuition to calibrated inference | Backtest one declared baseline | Reliable historic labels, splits, no leakage | PENDING; calibration/evaluation assets; not official odds |
| Tactics Lab | Turn watching into a tactical decision | Pause at a labelled decision and choose action | Annotated permitted rally / context | PROPOSED; authored learning scenarios |
| Creator Studio | Make an original narrative from owned content | Select own time ranges and create edit plan | Editing/distribution rights, credits | PROPOSED; no clip export implemented; original projects |
| Equipment Atlas | Connect equipment curiosity to real evidence | Open a dated equipment fact with source | Product imagery rights, reliable dated sources | PROPOSED; verifiable equipment catalogue; no invented endorsements |
| Fan Identity | Express interests through meaningful curation | Curate private favourites and observations | User opt-in, privacy choices | Local collection prototype only; no public profiles |
| PTTI Originals | Tell stories PTTI can actually publish | One authorized short interview | Consent, footage/music/likeness permissions | Production PENDING; owned editorial work |
| Pressure Notebook | Capture why a decision looked right before seeing result | Save pre-result reasoning and compare afterward | User notes and sourced result | PROPOSED; personal learning history |
| Watch Continuity | Preserve context through official-site detours | Return to player/star/filter state | Existing SAN return snapshot, eligible route | Existing interface reusable; cross-source test PENDING |

First recommended validation: Moment Passport vertical slice. Founder evaluates saving/revisiting ease and value; Main verifies identity semantics; Playback verifies seek boundary; SAN verifies return navigation. Do not expand the feature catalogue before this path works.
