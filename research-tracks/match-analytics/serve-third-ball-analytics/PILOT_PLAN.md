# Pilot plan

## Pilot 0 — Synthetic workflow test

**Status:** NOW / workflow preparation. Use the sample CSV to check schema reading, required columns, missing-value handling, and summary output.

## Pilot 1 — One real match

**Status:** NEXT / requires permitted video and a feasible annotation session.

Target 1 match and approximately 30–80 points. Measure whether the protocol can be applied, which variables are hard to judge, and how long annotation takes. Do not treat this as a representative sample.

## Pilot 2 — 3–5 matches

**Status:** FUTURE. Build an initial descriptive dataset only after Pilot 1 definitions are revised. Continue to report source, permissions, missingness, and uncertainty.

## Decision gates

Do not move to comparison or statistical association until the schema is stable enough to use, the data source is permitted, and the missing/unclear labels are visible.
