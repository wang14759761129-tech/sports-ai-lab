# Pilot 1 — Real Match Annotation Test

## Purpose

This pilot tests whether the current research protocol can be applied consistently to one real table tennis match. It has not reached annotation because the source video is currently inaccessible in the available browser session.

## Match

Zhou Qihao vs Tomokazu Harimoto, WTT Champions Macao 2026 Men's Singles Quarterfinal. The fixed sample boundary is Games 1–3: 5–11, 4–11, 8–11.

## Data

The 21-column file `data/raw/match_001_points.csv` has been created with no point rows. The expected sample is approximately 50 points. This is an access stop, not a result.

## Annotation experience

No annotation experience can be reported yet. The only observed methodological problem is that automated-access verification prevents frame-level viewing.

## Data quality and descriptive results

No point-level quality rates or descriptive results are reported. See `analysis/data_quality_report.md`.

## Method problems and protocol changes

No schema or protocol change was made. The protocol checkpoint is pending the first 10–15 observed points.

## Limitations

No real point data, no annotator agreement evidence, no video timestamps, and no descriptive conclusion are available. The project remains a method test.
